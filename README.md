# The Orc Horde

A top-down arcade horde shooter prototype developed with Unreal Engine 5.

## 🕹️ Project Overview
* **Genre:** Top-Down Arcade / Horde Shooter
* **Engine:** Unreal Engine 5
* **Core Technology:** Blueprints

## ✨ Key Features
* **Dynamic Enemy Spawning:** Spawns enemies with randomized stats to vary difficulty and gameplay.
* **Loot & Drop System:** Random item drops upon enemy defeat.
* **Scoring System:** Tracks player performance and progression.
* **Weapon System:** Handles weapon mechanics, targeting, and combat interactions.
